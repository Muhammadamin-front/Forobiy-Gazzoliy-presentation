# Forobiy va G‘azzoliy — taqdimot sayti

«Falsafa» fanidan veb-taqdimot: «Abu Nasr Forobiy va G‘azzoliyning falsafa ilmiga oid qarashlarini qiyosiy tahlil etish (Forobiyning «Siyosat falsafasi» va G‘azzoliyning «Kimyoi saodat» asarlari asosida)». Tayyorlagan: Dilorom Toyirova, 85-25 I guruh.

React + Vite + TypeScript + Tailwind CSS (shadcn tuzilmasi).

## Ishga tushirish

```bash
npm install
npm run dev      # http://localhost:5173
```

Taqdimot kuni: **F** — to‘liq ekran, **→ / ←** (yoki pult) — keyingi / oldingi qadam, **?** — yordam.

## Tahrirlash

Barcha matnlar, sanalar va manbalar: `src/lib/data.ts`.

- `coverflow.tsx` ← prompt.md (3D coverflow) — Forobiyning besh shahri
- `card-flip.tsx` ← flip-card.md — «Kimyoi saodat»ning to‘rt unvoni
- `text-roll.tsx` ← 2-prompt.md — «aql / qalb» savoli
- `splash-button.tsx` ← button.md
- `aurora-background.tsx` ← prompt-background-light.md — girih to‘ri
- pinned tarix zinapoyasi va qiyos sahnasi ← scroll-web.md
